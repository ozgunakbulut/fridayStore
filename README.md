# FridayStore

React Native (Expo) ile geliştirdiğim bir ürün vitrin uygulaması.  

## Özellikler
- Ürün listeleme
- Stok durumu takibi
- Basit ve düzenli arayüz
- Kategori ayrımı
- sepet ve sepete ekleme 

## Teknolojiler
- React Native  
- Expo  
- TypeScript
